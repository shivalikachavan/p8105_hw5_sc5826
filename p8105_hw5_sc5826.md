Plotting effect size vs. power

``` r
normal_dist_sim |> 
  group_by(mean) |> 
  summarize(
    power = sum(p.value < alpha) / n()
  ) |> 
  ggplot(aes(x = mean, y = power)) + 
  geom_point() +
  geom_line() + 
  xlab("True Mean (Effect Size)") + 
  ylab("Power") + 
  labs(
    title = "Effect Size vs. Power"
  ) 
```

<img src="p8105_hw5_sc5826_files/figure-gfm/unnamed-chunk-6-1.png" width="90%" />

There is an overall positive correlation between effect size and power.
When effect sizes are very small (\< 2), power is low. This means the
null hypothesis (𝜇 = 0) is failing to be rejected more often. At larger
effect sizes (\> 4), power is nearly 1. This means the null hypothesis
(𝜇 = 0) is being rejected nearly every time.

``` r
avg_estimates = 
  normal_dist_sim |> 
  group_by(mean) |> 
  summarize(avg_mu_hat = mean(mu_hat), n = n()) |> 
  mutate(estimates_source = "All Samples")

avg_estimates_null_rejected = normal_dist_sim |> 
  filter(p.value < 0.05) |> 
  group_by(mean) |> 
  summarize(avg_mu_hat = mean(mu_hat), n = n()) |> 
  mutate(estimates_source = "Filtered Samples (P < 0.05)")

rbind(avg_estimates, avg_estimates_null_rejected) |> 
  ggplot(aes(x = mean, y = avg_mu_hat, color = estimates_source)) + 
  geom_point() + 
  xlab("True Mean") + 
  ylab("Average Estimate of the Mean") + 
  labs(
    color = "Source of Average Estimate"
  )
```

<img src="p8105_hw5_sc5826_files/figure-gfm/unnamed-chunk-7-1.png" width="90%" />

The sample average of mû across tests for which the null is rejected is
only approximately equal to the true value of 𝜇 at larger effect sizes
(\> 4). These larger effect sizes are also the ones at which power is
nearly 1. As seen in the table below, as effect size increases, more
tests result in rejecting the null hypothesis. Filtering for the tests
where the p-value \< 0.05, means that we are only selecting samples that
are very extreme (since p-value means the probability of seeing a result
as extreme or more extreme than the result). When there is low power and
a small effect size, many tests will fail to reject the null hypothesis,
even if the data set is correctly estimating the true mean. This is also
seen in the table below, where there is a larger difference between
“avg_mu_hat_All Samples” and “avg_mu_hat_Filtered Samples (P \< 0.05)”
at smaller effect sizes.

There are 52179 observations in the `homicide_data` data set from the
Washington Post. Each homicide is noted by a unique identifier `uid`.
These homicides range from July 01, 2020 to December 12, 2020, though
about 49.6% of reported homicides have no `reported_date`. In most
homicides, there is information about the homicide victim like the name
(`last` and `first`) and demographic (`race`, `age`, and`sex`), the
location of the homicide (`city` and `state` as well as `lat` and
`long`), and disposition of the case (`Closed without arrest`,
`Closed by arrest`, or `Open/No arrest`).
